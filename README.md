## Sobre mí

Soy el fundador de **[Sistemas Digitales MG](https://sistemasmg.es)**, donde construyo herramientas SaaS para empresas sobre WordPress y Claude AI.

Me especializo en dos mundos que muy pocos combinan:

- **WordPress a nivel de ingeniería** — plugins de producción con arquitectura modular, tablas propias, APIs REST, multi-tenant y WooCommerce Subscriptions
- **Claude AI como plataforma** — creo Skills, MCP servers y agentes especializados que integran WordPress con inteligencia artificial para automatizar procesos de negocio reales

Más de 5 años desarrollando plugins PHP complejos. Más de 2 años construyendo con la API de Claude y el ecosistema MCP.

## Lo que construyo

### 🔌 WordPress Plugins de producción

Arquitectura modular real: cada módulo con sus propias tablas (`mg_*`), endpoints REST, sistema de permisos por cliente y activación dinámica por plan de suscripción. Sin depender de plugins de terceros para lo crítico.

### 🤖 Claude AI — Skills & MCP Servers

MCP servers en Python que exponen WordPress y herramientas de negocio a Claude Desktop. Skills reutilizables para gestionar sitios, lanzar agentes especializados y automatizar flujos que antes requerían intervención manual.

### ☁️ SaaS Multi-tenant sobre WordPress

Plataformas completas: sistema de licencias propio, dashboards por cliente, Stripe + WooCommerce Subscriptions, módulos activables por plan. Arquitectura pensada para escalar sin tocar el core.
